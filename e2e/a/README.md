เทสต์ของคน A (แจ้งปัญหา, คำร้องของฉัน, ศูนย์มอบหมายงาน, งานที่ได้รับมอบหมาย, พนักงาน, ทรัพย์สิน, ผู้ใช้, Login)

ไฟล์ที่ลงท้าย `.mobile.spec.ts` จะรันบนจอขนาดมือถือ (Pixel 7) — ใช้กับหน้าแจ้งปัญหาบนมือถือ

| ไฟล์ | ครอบคลุม |
|---|---|
| `access.spec.ts` | สิทธิ์เปิดเมนูของแต่ละบทบาท, ยังไม่ล็อกอินถูกพาไปหน้า Login, รหัสผิด |
| `tickets.spec.ts` | วงจรงานซ่อมครบ: แจ้งพร้อมรูป → มอบหมาย → เบิกอะไหล่ (ตัดสต็อก, เบิกเกินไม่ได้) → แก้เสร็จ → ผู้แจ้งให้คะแนนปิดงาน / "ยังไม่หาย", สิทธิ์ดูรูป |
| `users.spec.ts` | Admin สร้างบัญชี (รหัส ≥ 8 ตัว, username ซ้ำไม่ได้), ถอดสิทธิ์ตัวเองไม่ได้, ระงับบัญชีแล้วหลุดทันที |

| `forgot-password.spec.ts` | ลืมรหัสผ่าน: ตอบเหมือนกันทุกกรณี, จำกัด 3 ครั้ง/ชม., ลิงก์ใช้ครั้งเดียว/หมดอายุ |
| `ticket-new.mobile.spec.ts` | แจ้งปัญหาบนมือถือ (Pixel 7): ไม่ล้นจอ, ช่องกรอก 16px, ปุ่มถ่ายรูปเปิดกล้อง, ปุ่มส่งติดขอบล่าง, แจ้งปัญหาพร้อมรูปได้จริง |
| `work.mobile.spec.ts` | งานที่ได้รับมอบหมายบนมือถือ: ไม่ล้นจอ, ตัวกรองสถานะ, ปุ่มโทรผู้แจ้ง, ปุ่มสถานะแตะครั้งเดียว + บันทึก, ประวัติ, เบิกอะไหล่ด้วยปุ่ม −/+ |
| `dispatch.mobile.spec.ts` | ศูนย์มอบหมายงานบนมือถือ: ไม่ล้นจอ, แตะตัวเลข "เกิน SLA" เพื่อกรอง, ตัวกรองสถานะ, ปุ่มโทรผู้แจ้ง, เลือกช่างเต็มความกว้าง (16px) → มอบหมาย / เปลี่ยนผู้รับผิดชอบ, ประวัติ |
| `consistency.spec.ts` | กฎที่ต้องตรงกันทุกเมนู: ถอดสิทธิ์/ระงับช่างแล้วเตือนงานค้าง, ศูนย์มอบหมายงานติดป้าย + ตัวกรอง "ต้องมอบหมายใหม่" + แจ้งเตือน และไม่เสนอช่างที่รับงานไม่ได้, ส่งมอบอุปกรณ์ใช้กฎ Asset Tag และสิทธิ์เดียวกับทะเบียน, ห้ามเบิกอะไหล่หลังแจ้งซ่อมเสร็จ |
| `work-photos.spec.ts` | ช่างแนบรูปตอนอัปเดตงาน: เลือก/ลบรูปก่อนส่ง, แนบรูปอย่างเดียวได้, รูปผูกกับประวัติแต่ละครั้ง, แยกเป็น "รูปจากช่าง", ผู้แจ้งเห็น แต่พนักงานอื่นเปิดไม่ได้ |
| `notifications.spec.ts` | อีเมลแจ้งเตือน: คำร้องใหม่→IT Manager/Admin, มอบหมาย→ช่าง, ซ่อมเสร็จ→ผู้แจ้ง, ยังไม่หาย→ช่าง, ปิดงาน+คะแนน→ช่าง, ไม่ส่งให้คนที่กดเอง (อ่านจาก `MAIL_OUTBOX_DIR`) |
| `asset-scan.mobile.spec.ts`, `asset-scan-camera.mobile.spec.ts` | ปุ่มสแกน Asset Tag: อ่าน QR จากกล้อง (กล้องจำลองด้วยวิดีโอ), ไม่มีกล้อง→อ่านจากรูปถ่าย Code 128, รูปที่ไม่มีบาร์โค้ด, ยกเลิก, ไฟล์ WASM เสิร์ฟจากแอปเอง |
| `storefront.spec.ts` | หน้าร้าน: หน้าแรก (หมวด/สินค้า), ค้นหาทุกคำ, สินค้าที่ปิดไว้ไม่แสดง/404, กรองหมวด+ยี่ห้อ, เรียงราคา, มีสินค้าเท่านั้น, หน้าสินค้า (ราคา/ส่วนลด/คงเหลือ/ประกัน/สเปค) |
| `storefront.mobile.spec.ts` | หน้าร้านบนมือถือ: ไม่ล้นจอ, ตัวกรองเลื่อนแนวนอน, 2 การ์ดต่อแถว, ช่องค้นหา 16px |
| `customer-auth.spec.ts` | ลูกค้า: สมัคร (ตรวจอีเมล/รหัส ≥ 8/ยืนยันรหัส/เบอร์/ซ้ำ, เก็บ hash), เข้า/ออกจากระบบ, หน้าบัญชี, บัญชีถูกระงับ, กลับไป /checkout หลัง login, ไม่พาไปเว็บอื่น, session ลูกค้าเข้าหลังร้านไม่ได้ |
| `cart.spec.ts` | ตะกร้า: ผู้เยี่ยมชมมีตะกร้าเอง (cookie + เก็บแค่ hash), จำกัดตามสต็อก, เพิ่ม/ลด/ลบ, ใกล้ส่งฟรี, login แล้วรวมเข้าตะกร้าลูกค้า (จำกัดตามสต็อก) ไปต่อ /checkout, รายการที่ขายไม่ได้แล้วกันการสั่งซื้อ |
| `my-orders.spec.ts` | คำสั่งซื้อของฉัน: เห็นเฉพาะของตัวเอง ใหม่สุดก่อน, ปุ่มถัดไปตามสถานะ (ชำระเงิน / ติดตามพัสดุ / ดูรายละเอียด), รอชำระที่เลยเวลาแสดงหมดเวลา, แท็บสถานะพร้อมจำนวน, หน้าบัญชีแสดง 3 รายการล่าสุด, ลิงก์ /pay ตอนยังไม่ login กลับมาหลังเข้าสู่ระบบ |
