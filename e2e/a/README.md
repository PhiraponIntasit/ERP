เทสต์ของคน A (แจ้งปัญหา, คำร้องของฉัน, ศูนย์มอบหมายงาน, งานที่ได้รับมอบหมาย, พนักงาน, ทรัพย์สิน, ผู้ใช้, Login)

ไฟล์ที่ลงท้าย `.mobile.spec.ts` จะรันบนจอขนาดมือถือ (Pixel 7) — ใช้กับหน้าแจ้งปัญหาบนมือถือ

| ไฟล์ | ครอบคลุม |
|---|---|
| `access.spec.ts` | สิทธิ์เปิดเมนูของแต่ละบทบาท, ยังไม่ล็อกอินถูกพาไปหน้า Login, รหัสผิด |
| `tickets.spec.ts` | วงจรงานซ่อมครบ: แจ้งพร้อมรูป → มอบหมาย → เบิกอะไหล่ (ตัดสต็อก, เบิกเกินไม่ได้) → แก้เสร็จ → ผู้แจ้งให้คะแนนปิดงาน / "ยังไม่หาย", สิทธิ์ดูรูป |
| `people.spec.ts` | เพิ่ม/แก้/ลบพนักงาน, ลงทะเบียนและส่งมอบอุปกรณ์, หนึ่ง Tag ถือได้คนเดียว, ลบพนักงานแล้วอุปกรณ์คืนคลัง |
| `users.spec.ts` | Admin สร้างบัญชี (รหัส ≥ 8 ตัว, username ซ้ำไม่ได้), ถอดสิทธิ์ตัวเองไม่ได้, ระงับบัญชีแล้วหลุดทันที |
| `password.spec.ts` | เปลี่ยนรหัสผ่านเอง: ตรวจความถูกต้อง, อุปกรณ์อื่นถูกออกจากระบบ |
| `forgot-password.spec.ts` | ลืมรหัสผ่าน: ตอบเหมือนกันทุกกรณี, จำกัด 3 ครั้ง/ชม., ลิงก์ใช้ครั้งเดียว/หมดอายุ |
| `ticket-new.mobile.spec.ts` | แจ้งปัญหาบนมือถือ (Pixel 7): ไม่ล้นจอ, ช่องกรอก 16px, ปุ่มถ่ายรูปเปิดกล้อง, ปุ่มส่งติดขอบล่าง, แจ้งปัญหาพร้อมรูปได้จริง |
| `work.mobile.spec.ts` | งานที่ได้รับมอบหมายบนมือถือ: ไม่ล้นจอ, ตัวกรองสถานะ, ปุ่มโทรผู้แจ้ง, ปุ่มสถานะแตะครั้งเดียว + บันทึก, ประวัติ, เบิกอะไหล่ด้วยปุ่ม −/+ |
| `asset-scan.mobile.spec.ts`, `asset-scan-camera.mobile.spec.ts` | ปุ่มสแกน Asset Tag: อ่าน QR จากกล้อง (กล้องจำลองด้วยวิดีโอ), ไม่มีกล้อง→อ่านจากรูปถ่าย Code 128, รูปที่ไม่มีบาร์โค้ด, ยกเลิก, ไฟล์ WASM เสิร์ฟจากแอปเอง |

กติกาในโฟลเดอร์นี้: ไม่แก้บัญชีตัวอย่าง (รหัส `1234` ต้องใช้ได้เสมอ เพราะเทสต์ของคน B ใช้) — สร้างบัญชี/ข้อมูลทดสอบที่ขึ้นต้นด้วย `e2e-` / `E2E` เอง แล้วลบใน `afterAll` (`util.ts` มีตัวช่วย `as()`, `makeUser()`, `dropUsers()`)
